GUIA DE LA PRACTICA: TABLAS DE ENRUTAMIENTO IPv4
================================================
Material de repaso y memoria de la practica

1. QUE PIDE REALMENTE EL EJERCICIO
---------------------------------
Instruccion de entrega comunicada por el profesor:
"Elige un router y calcula sus tablas de encaminamiento. El ejemplo esta relleno con las tablas de encaminamiento de RA."

Por tanto, para entregar basta con elegir UN router y preparar su tabla
(RB, RC, RD o RE). En nuestro estudio hemos elaborado las cinco tablas
para practicar. Se recomienda RD como opcion de entrega: tiene dos redes
conectadas y permite demostrar que se sabe elegir la interfaz de salida.

IMPORTANTE: el fichero original de RA es un ejemplo del profesor. Algunas
mascaras de ese Excel difieren de los /24 que aparecen en el esquema.
No podemos explicar con certeza esa diferencia sin instrucciones adicionales.
Para NUESTRA solucion se respetan los prefijos /24 del esquema y se usan
las IP asignadas a continuacion; no se modifica el fichero del profesor.

2. TOPOLOGIA Y REDES
--------------------
LAN A 192.168.2.0/24 --- RA --- SW1 (192.168.1.0/24) --- RB --- LAN B 192.168.3.0/24
                               |
                               RD
                               |
                         SW2 (192.168.0.0/24)
                            /       \
                           RC        RE --- ISP --- Internet
                           |
                    LAN C 192.168.4.0/24

Nota: el dibujo es esquematico; RA, RB y RD comparten SW1, y
RC, RD y RE comparten SW2. Un switch no es un salto de enrutamiento.

Redes internas segun el enunciado:
  SW1:   192.168.1.0/24
  SW2:   192.168.0.0/24
  LAN A: 192.168.2.0/24
  LAN B: 192.168.3.0/24
  LAN C: 192.168.4.0/24

3. DIRECCIONES IP ELEGIDAS
--------------------------
El enunciado permite asignar a voluntad las IP de las interfaces.
Estas son las usadas de forma consistente en las cinco tablas:

  RA - SW1:    192.168.1.1/24
  RA - LAN A:  192.168.2.1/24
  RB - SW1:    192.168.1.2/24
  RB - LAN B:  192.168.3.1/24
  RD - SW1:    192.168.1.3/24
  RD - SW2:    192.168.0.1/24
  RC - SW2:    192.168.0.2/24
  RC - LAN C:  192.168.4.1/24
  RE - SW2:    192.168.0.3/24

Para ilustrar el enlace externo de RE se propuso:
  RE - ISP:    203.0.113.2/30
  ISP - RE:    203.0.113.1/30
  Red enlace:  203.0.113.0/30

203.0.113.0/24 es un bloque reservado para documentacion (RFC 5737).
NO representa un ISP real ni es un dato facilitado por el profesor.

4. CONCEPTOS IMPORTANTES
------------------------
ROUTER: dispositivo que decide por donde reenviar paquetes entre redes.
TABLA DE ENRUTAMIENTO: conjunto de rutas que un router consulta para
 elegir la salida de un paquete en funcion de su IP de destino.
RED DE DESTINO: red a la que queremos llegar (ej.: 192.168.4.0).
MASCARA/PREFIJO: delimita que parte de la IP identifica la red.
  /24 = 255.255.255.0; /30 = 255.255.255.252;
  /32 = 255.255.255.255; /0 = 0.0.0.0.
SALTO SIGUIENTE (next hop): IP del ROUTER VECINO al que se envia el paquete.
INTERFAZ DE SALIDA: interfaz LOCAL del router que estamos configurando.
  En estas tablas se identifica con su propia direccion IP.
RUTA DIRECTA: la red esta conectada a una interfaz propia; indicamos *
  en salto siguiente, segun el formato del ejemplo.
RUTA ESTATICA: ruta configurada expresamente hacia una red remota.
RUTA POR DEFECTO: 0.0.0.0/0; se aplica cuando no coincide otra ruta
  mas especifica. La ruta por defecto no se usa si ya existe una mejor.
LOOPBACK: 127.0.0.1/32, direccion local al propio dispositivo;
  se incluye para seguir el formato del ejemplo del profesor.
SWITCH: conecta equipos en la misma LAN; no se escribe como siguiente salto.
CAMINO DE IDA Y VUELTA: para poder comunicarse en ambos sentidos, debe
  existir enrutamiento de retorno; con Internet real normalmente se usa NAT.

5. METODO PASO A PASO PARA RESOLVER CUALQUIER TABLA
---------------------------------------------------
Paso 1. Elige el router cuya tabla tienes que construir.
Paso 2. Escribe todas las redes que aparecen en el esquema.
Paso 3. Marca las redes directamente conectadas al router.
Paso 4. Anota sus IP de interfaz y las mascaras de esas redes.
Paso 5. Para cada red remota, sigue el camino en el dibujo hasta ella.
Paso 6. En "salto siguiente" anota SOLO la IP del primer router vecino.
Paso 7. En "interfaz" anota la IP PROPIA por la que sales hacia ese vecino.
Paso 8. Copia el prefijo de la red destino, no el de tu interfaz de salida.
Paso 9. Agrega ruta por defecto si existe salida a otros destinos.
Paso 10. Comprueba que cada salto siguiente se puede alcanzar directamente,
  que no hay IP duplicadas y que las rutas permiten volver al origen.

Ejemplo A: desde RD hacia LAN A (192.168.2.0/24)
  Camino: RD -> RA -> LAN A
  Salto siguiente: 192.168.1.1 (IP de RA en SW1)
  Interfaz salida: 192.168.1.3 (IP de RD en SW1)

Ejemplo B: desde RD hacia LAN C (192.168.4.0/24)
  Camino: RD -> RC -> LAN C
  Salto siguiente: 192.168.0.2 (IP de RC en SW2)
  Interfaz salida: 192.168.0.1 (IP de RD en SW2)

7. EXPLICACION ESPECIAL DE RD
----------------------------
RD es el router situado entre SW1 y SW2:

- SW1 y SW2 son redes directamente conectadas: siguiente salto *.
- LAN A: RD -> RA, por SW1. Next hop 192.168.1.1,
  interfaz local 192.168.1.3.
- LAN B: RD -> RB, por SW1. Next hop 192.168.1.2,
  interfaz local 192.168.1.3.
- LAN C: RD -> RC, por SW2. Next hop 192.168.0.2,
  interfaz local 192.168.0.1.
- Internet: RD -> RE, por SW2. Next hop 192.168.0.3,
  interfaz local 192.168.0.1.

La IP del salto siguiente NO es la misma que la interfaz local:
  Salto siguiente = direccion del VECINO.
  Interfaz = direccion PROPIA.

8. COMO SELECCIONA UN ROUTER UNA RUTA
-------------------------------------
El router compara la IP destino con los prefijos de la tabla y usa
la coincidencia de prefijo mas largo (longest prefix match).
Ejemplo: 192.168.4.50 coincide con 192.168.4.0/24 y 0.0.0.0/0;
se elige /24, por ser mas especifica.

Las tablas de la practica enumeran rutas explicitas para estudiar.
En un router real algunas rutas estaticas podrian ser redundantes si
la ruta por defecto ya conduce correctamente al mismo siguiente salto.

9. ERRORES TIPICOS Y COMPROBACIONES
----------------------------------
[ ] Poner como salto siguiente el router FINAL en vez del PRIMER vecino.
[ ] Escribir como interfaz de salida una IP que pertenece a otro router.
[ ] Confundir direccion de red (192.168.4.0) con host (192.168.4.1).
[ ] Copiar la mascara de la interfaz propia en vez de la mascara destino.
[ ] Usar /26, /28 o /30 donde el dibujo indica /24.
[ ] Escribir 0.0.0.0/24: la ruta por defecto correcta es 0.0.0.0/0.
[ ] Suponer que el switch funciona como router.
[ ] Olvidar la ruta de retorno en una comunicacion bidireccional.
[ ] Creer que tener ruta a ISP garantiza Internet real: pueden hacer
    falta NAT, DNS, configuracion de ISP, politicas y rutas de retorno.

10. RESUMEN PARA EL EXAMEN
--------------------------
1) UNA TABLA POR ROUTER, aunque en ESTA entrega solo piden elegir uno.
2) RED DIRECTA -> * en salto siguiente; interfaz propia de esa LAN.
3) RED REMOTA -> IP del primer ROUTER vecino, no la IP del destino.
4) INTERFAZ -> IP propia que permite alcanzar ese vecino.
5) /24 -> 255.255.255.0; /30 -> 255.255.255.252.
6) RUTA POR DEFECTO -> 0.0.0.0/0.
7) MAS ESPECIFICA GANA: /24 antes que /0.
8) Para RD: hacia A y B se sale por 192.168.1.3;
   hacia C e Internet se sale por 192.168.0.1.
